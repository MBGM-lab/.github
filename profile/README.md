# Multiscale Basal Ganglia Modeling lab

We develop computational models and simulation tools for understanding basal ganglia circuits at multiple scales — from single neurons and local microcircuits to large-scale network dynamics and behaviour.

**KTH Royal Institute of Technology** · Department of Computational Science and Technology

---

## Research

- Large-scale data-driven network models of the basal ganglia
- Synaptic connectivity and structural plasticity
- Action selection and reinforcement learning in cortico-basal ganglia loops
- Open-source simulation tools for reproducible computational neuroscience

---

## Software

### [Snudda](https://github.com/Hjorthmedh/Snudda)

Large-scale network simulation framework for the basal ganglia. Snudda creates the connectivity for a detailed network model, places neurons in 3D, connects them based on morphology and experimental data, and runs simulations with NEURON.

### [ddigitize](https://github.com/MBGM-lab/ddigitize) · [live app](https://MBGM-lab.github.io/ddigitize/)

Browser-based tool for extracting numerical data from scientific figures using smooth C¹-continuous cubic Bézier curves. No installation required — runs entirely in the browser.

### [treem](https://github.com/a-tsiber/treem)

Tool for editing and analyzing reconstructed neuronal morphologies in SWC format.
